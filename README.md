🎓 Student Placement Analytics Dashboard using Power BI
📌 Project Overview

The Student Placement Analytics Dashboard is an interactive Power BI project designed to analyze student placement performance, salary trends, and employability skills. This dashboard helps users understand placement statistics, salary distribution, and skill-based insights through interactive visualizations.

🎯 Objectives
Analyze overall student placement performance.
Compare salary packages across different branches.
Identify employability trends using coding, communication, and internship data.
Provide meaningful insights for students and educational institutions.
🛠️ Tools Used
Power BI Desktop
Microsoft Excel / CSV Dataset
Power Query
DAX (Data Analysis Expressions)
📂 Dataset

The dataset contains student academic and placement information, including:

Student ID
Branch
Gender
CGPA
Coding Skill Score
Communication Skill Score
Internship Count
Certifications
Placement Status
Salary Package (LPA)
College Tier
GitHub Repositories
LinkedIn Connections
